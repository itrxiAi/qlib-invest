# 单条资讯深度分析

输入是一条资讯事件（JSON），输出是该条的深度分析（Markdown）。

## 输入

通过 prompt 接收一个 JSON 对象：

```json
{
  "id": 1,
  "title": "事件标题",
  "source": "techmeme|twitter|web_search",
  "time": "事件时间",
  "link": "链接",
  "score": 5,
  "category": "新增|更新",
  "raw_text": "原始资讯文本"
}
```

## 分析步骤

1. **理解事件**：从 `raw_text` 和 `title` 提取核心事实，不复述。

2. **联网查证**（≥4 分必须，3 分可选）：用 `web_fetch` 搜索历史类似事件：
   - 查历史类比：类似事件当时发生了什么、后续走向如何
   - 查量级：历史类似事件的实际影响量级
   - 每轮搜索后思考：是否找到可类比的历史事件？是否有足够信息推演走向？
   - **收敛条件**（任一即停）：找到历史类比并据此推演出本次事件可能走向；连续一轮无新增信息；最多 3 轮。无果则简单带过。

3. **输出分析结果**。

## 输出格式

```
★★★★★ 事件标题（你总结的，不是原文标题）（来源 时间）
  后续推演：历史类比后续走向 → 本次事件可能发展方向及受影响资产/主体（1-2 句）
  跨事件关联：跟本轮/历史哪些事件共同指向什么信号（1 句）
```

**要求**：
- 后续推演必须基于历史类比，不是描述"市场该怎么解读"
- 挖深层原因，不停留表象
- 收敛后输出 1-2 句深度足够的重点，不要注水

## 输出文件

将分析结果写入 `runs/tmp/analyze_{id}.md`，内容仅为上述格式的分析文本（不含 JSON、不含多余解释）。
