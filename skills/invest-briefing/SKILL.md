# 更新局势简报

每轮深度分析存档完成后执行。输入是本轮 `runs/news_deep/{date}_{hour}.md` 存档文件名（由调用方给出）。所有路径相对项目根目录（含 `cli.py` 和 `runs/` 的目录）。

## briefing.md 格式契约（权威定义，唯一真相源）

```markdown
# 全球科技与宏观局势简报

> 上次更新：YYYY-MM-DD HH:MM

## 核心判断

1. **判断标题**：一段完整表述（2-4 句）
...

## 追踪中事件

| 事件 | 状态 | 上次更新 |
|------|------|----------|
| 事件名 | [新增]/[更新] + 一句话最新状态（可含多条增量，分号分隔） | YYYY-MM-DD HH:MM |
```

**只有这三个部分**。不写"本轮新增"流水、不写"已归档"——过期行由脚本自动删除（`BRIEFING_STALE_DAYS` 天未更新的追踪行会被 `cli.py clean-briefing` 移除，默认 3 天）。

## 更新规则

1. 读 `runs/news_deep/{date}_{hour}.md`，再读 `runs/briefing.md`
2. `上次更新` 改为本轮时间
3. **核心判断**：重写为当前最重要的 3-5 条，不逐条累积
4. **追踪中事件**：
   - 本轮 `[更新]` 类事件 → 改对应行的状态、时间戳
   - 本轮 `[新增]` 类事件 → 新增一行
   - 修正旧判断时在状态里标注 `[修正]`，不要静默改
   - 本文件没有"已归档"区，已死事件不用管（脚本会按时间清理）
5. 文件不存在则按上面契约新建，`上次更新` 填本轮时间
